# 英単語帳（フラッシュカードアプリ）

フレームワーク無しの HTML / CSS / JavaScript だけで作った、シンプルな英単語学習アプリ。
ビルド不要なので、VS Codeでそのまま開いて動かせるで。

## VS Codeでの動かし方

1. このフォルダを VS Code で開く（`ファイル > フォルダーを開く`）
2. 拡張機能タブから **Live Server**（作者: Ritwick Dey）をインストール
3. `index.html` を右クリック → **「Open with Live Server」**
4. ブラウザが自動で開いて動く（保存すると自動リロードされるのが便利）

## 機能

- 単語（英語）／発音（任意）／意味（日本語）のフラッシュカード
- 出題順の切り替え（シャッフル／順番通り／「もう一回」優先）
- 「わかった」「もう一回」で習熟度を記録（ブラウザの localStorage に保存）
- 単語の追加（単語50文字まで／発音50文字まで／意味1000文字まで）・削除
- JSON形式での書き出し（`words.json`）

## PC登録 → iPhone閲覧の運用方法

このアプリはサーバーを持たへんから、PCで登録した単語をiPhoneでそのまま見るには、
一手間だけ必要やで。

1. **PCで単語を登録する**（「単語管理」タブからいつも通り追加）
2. ある程度たまったら「JSONで書き出し」ボタンを押す → `words.json` がダウンロードされる
3. ダウンロードした `words.json` を、GitHubリポジトリの **ルート**（index.htmlと同じ階層）にアップロードして、既存の `words.json` を上書きする
4. iPhoneのSafariで公開URLを開くと、アップロードした最新の単語が表示される

### データの優先順位（アプリが自動で判定する）

1. そのブラウザに編集履歴（localStorage）があればそれを使う → **PC側はこれで継続編集できる**
2. なければ `words.json` を読み込む → **iPhoneなど閲覧専用端末はここが使われる**
3. どっちも無ければ、最初から入ってるサンプル単語を使う

画面上部の小さい表示（「◯◯を表示中」）で、今どのデータを見てるか確認できるで。

## コードの構成

```
index.html   … 画面の骨組み（構造）
style.css    … 見た目（配色、カードのフリップアニメーションなど）
script.js    … 動きの部分（状態管理、保存、判定、words.json読み込みロジック）
words.json   … 書き出し先／読み込み元のデータファイル（雛形入り）
```

## GitHub Pagesへの公開手順（概要）

1. GitHubでアカウント作成（無料）
2. 新しいリポジトリを作成し、このフォルダの中身（`index.html`, `style.css`, `script.js`, `words.json`）をアップロード
3. リポジトリの `Settings > Pages` で、公開元ブランチを `main`、フォルダを `/(root)` に設定
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになる
5. このURLをiPhoneのSafariでブックマーク（「ホーム画面に追加」がおすすめ）

※ 無料の個人アカウントでは、Pagesは**パブリックリポジトリ**でのみ使える点に注意（URLを知ってる人は誰でもアクセス可能な状態になる）。

## 触ってみると勉強になりそうなポイント

- **`fetch()`** — 起動時に `words.json` を非同期で取りに行く処理。`async/await`とセットで使ってる。
- **`localStorage`** — ブラウザ内保存の仕組み。PC側の「編集中データ」の置き場所として使ってる。
- **データの優先順位ロジック** — `initWords()`関数の中で「localStorage → words.json → サンプル」の順に試してるとこ。実務でもよくある「キャッシュ優先、無ければフェッチ」のパターン。
- **`maxlength`属性とJS側での`.slice()`** — フォームの文字数制限は、HTML側の`maxlength`とJS側の二重チェックにしてる（入力を横着してAPI直叩きされても超過を防げる、という考え方）。
